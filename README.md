# Mini Compiler - Lexer & Parser

## Overview

This project is a simple compiler front-end developed in Python. It performs lexical analysis and syntax analysis on user-provided source code through a graphical user interface.

## Features

* Lexical Analysis (Lexer)
* Syntax Analysis (Parser)
* Token Generation
* Error Detection
* Tkinter-Based GUI

## Technologies

* Python
* Tkinter

## Project Structure

* lexer.py → Tokenization and lexical analysis
* parser.py → Syntax analysis and parsing
* mainUI.py → Graphical user interface

## Educational Purpose

This project was developed as part of a System Programming course to demonstrate the fundamental stages of compiler design.
